# NotchOS website

The product page for NotchOS, live at **https://notchos-mac.github.io**.

Built with Vite, React, TypeScript, Tailwind CSS and Motion. Every push to `main` rebuilds and publishes
the site through GitHub Pages.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Prices, links and the support email live in `src/site.ts`.
